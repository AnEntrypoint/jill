jev-local

jev-local answers small typed questions about a piece of text, using a claude-haiku-5-5 subagent in place of a cloud decision model.

npx skills add AnEntrypoint/richard

Or add it as a plugin: /plugin marketplace add AnEntrypoint/richard, then /plugin install jev-local@richard.

How it works

  1. Prepare chunks

    Group the questions that share one state into chunks of up to eight.

  2. Dispatch Haiku subagents in parallel

    Send one claude-haiku-5-5 subagent per chunk, all in one message. Each replies with JSON only.

  3. Merge

    Check that every question has exactly one answer, that choices are real options and that scores sit in range. Anything invalid is flagged, never guessed.

Three question types

Each question has one of three types.

Choice

Pick one option.

{"id": "lane", "type": "choice",
 "question": "Which lane?",
 "options": ["billing", "shipping", "support", "spam"]}

Score

Place the state (the text being judged) on a scale.

{"id": "urgency", "type": "score",
 "question": "How urgent?",
 "scale": [0, 1]}

Noul

Is a yes or no statement true of the state?

{"id": "refund", "type": "noul",
 "question": "The customer asks for a refund."}

Example reply

{"id": "lane", "value": "billing", "confidence": 0.97}

One answer, in the shape the skill documents. Every answer carries its own confidence from 0 to 1. This one is an example, not a measured result.

Eight ready-made policies

Question sets for common decisions, ready to paste into a batch.

  • Model routing: the cheapest model tier good enough for a turn. Risky work never goes to the cheapest tier.
  • Skill selection: which installed skill a turn needs, or none.
  • Triage: what kind of message it is, how urgent, and whether a person must see it now.
  • Mailbox lanes: which lane a message belongs in, and whether it deserves attention.
  • Memory filter: which retrieved passages help answer the current question.
  • Turn selection: which turns to keep when a transcript has to be cut.
  • Injection screen: whether a piece of web or tool output tries to instruct an agent.
  • Command gate: whether a shell command is safe to run without review.
